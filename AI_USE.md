# AI and Heuristics Use Disclosure

## Overview
This document transparently describes how AI and machine learning technologies are utilized within the VideoEngine system. In accordance with honest engineering principles, we strictly distinguish deterministic heuristic algorithms from machine learning or large language model (LLM) components.

## 1. Script Generation: Deterministic Heuristics (No LLM)
- **Method**: The default script generator employs an analytical term-frequency (TF) and sentence-scoring heuristic rather than an LLM.
- **Why**: Eliminates third-party API dependencies, token fees, latency, and hallucination risks. It ensures deterministic, reproducible script segmentation from PDF source material while preserving exact page attributions.
- **Attribution in Output**: The API and generated `manifest.json` report the script generation provider explicitly as `"heuristic"` and never falsely claim LLM or generative AI authorship.

## 2. Text-to-Speech (TTS)
- **Adapters Available**:
  - `gtts`: Free Google Translate text-to-speech engine.
  - `edge`: Microsoft Edge neural text-to-speech synthesizing high-quality neural voices.
  - `espeak`: Rule-based formant speech synthesizer (offline, no neural network).
  - `mock`: Synthetic tone generator for offline test runs and CI pipelines without network access.
- **Provider Flagging**: When mock speech is used, a clear warning is attached to the job metadata and manifest (`is_mock=True`).

## 3. Footage Retrieval & Keyword Matching
- **Search Query Construction**: Queries are generated by extracting top descriptive nouns and keywords from scene texts, combined with visual style modifiers (e.g., `cinematic`, `documentary`, `corporate`).
- **Ranking**: Results from the Pexels video search API are scored and ranked based on textual tag and title overlap.
- **Relevance & Avoid Constraints**: Candidates falling below the minimum relevance threshold (`FOOTAGE_MIN_RELEVANCE`) or matching exclusion filters (`avoid` list) are filtered out.

## 4. Audio Input Transcription
- **Adapter**: Supports local OpenAI Whisper (speech-to-text transformer model) when installed, alongside a deterministic mock transcriber for test isolation.
- **Model Size**: Defaults to Whisper's `tiny` or `base` weights to avoid prohibitive memory footprints on lightweight developer hardware.
